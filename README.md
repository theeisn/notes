# Notes for Path of Exile 2
## AutoHotkey script to keep notes

This is designed to be a lightweight and single purple tool that does only notes.

**Requirement**
* AutoHotkey v2 installed

**How to install**
1. Downloaded the latest Source Code archive from the [releases](https://theeisn/notes/releases) page;
2. Extract everything in the same folder;
3. Double click on notes.ahk

**How to use**
* Press CTRL+SHIFT+O to toggle the options menu

**Is it safe to use?**
Absolutely. This tool works by reading the client.txt log file and is created following [GGG's policy for developers](https://www.pathofexile.com/developer/docs/index#policy).


## Future functionality
Currently this has the minimum functionality I need in time for the 0.5 patch. As I have more time after I will work on making it better, but this will not grow into huge new functionality (but rather more flexibility in choosing how to display the notes).

I would also like to add an import notes option.
